◆ kCanonicalFlag

KeyButton deskflow::scancode::kCanonicalFlag = 0x8000
inlineconstexpr

Marks a wire KeyButton as a canonical PC Set-1 scancode.

Canonical scancodes occupy the low 9 bits, the same range KeyState masks a server key handle down to, so this bit is free on every platform. A primary sets it only when it can actually produce Set-1 codes, which makes the raw-scancode path opt-in per key: a secondary that sees an unmarked button falls back to the translated key path instead of reading a foreign platform key button as Set-1. The primary sends the flag only to peers that negotiated protocol 1.10, so older peers never see it and never take the flagged raw path.
