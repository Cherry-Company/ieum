# Pro Local 파일 전송

`0.1.0-alpha.21`부터 Windows 파일 보내기와 받기는 유효한 Pro Local 라이선스가 필요한 기능입니다.
로컬 KVM, IME 동기화와 클립보드에는 라이선스가 필요하지 않습니다.

## 준비물

- 파일 전송에 참여하는 Windows PC 두 대 모두 `0.1.0-alpha.21` 이상
- 두 PC를 연결한 기존 Ieum 구성
- 두 PC 모두에서 켠 TLS
- 소유자에게 받은 한 줄짜리 `*.ieum-license.txt` 파일

현재 화면 경계 드래그 경로는 Windows 서버에서 Windows 클라이언트로 보냅니다. 반대 방향 드래그,
전송별 승인 창, 진행률, 일시정지·재개와 원격 앱에 바로 놓기는 이후 구현 순서입니다.

## 활성화

두 Windows PC 각각에서 다음을 수행합니다.

1. **환경설정 → Files**를 엽니다.
2. **Import license file…**을 눌러 받은 `*.ieum-license.txt`를 선택합니다.
3. 상태가 유효하다고 표시되면 **Activate**를 누릅니다.
4. TLS를 켭니다.
5. 필요한 역할에 따라 **Send files…** 또는 **Receive files…**를 직접 켭니다.
6. 받는 PC에서는 절대 경로인 저장 폴더를 확인합니다. 기본값은 `Downloads/Ieum`입니다.

후원자에게 전달되는 파일은 `*.ieum-license.txt` 하나뿐입니다. 발급 영수증, 발급대장, 발급 프로그램과
서명용 개인키는 프로젝트 소유자 자료이므로 배포하지 않습니다.

## 동작과 안전 경계

- 제어 메시지는 프로토콜 1.12, 데이터 메시지는 프로토콜 1.13 이상에서만 협상됩니다.
- 프로토콜 기능을 상대가 지원하더라도 로컬 라이선스가 유효하지 않으면 제안이나 데이터가 나가지 않습니다.
- 양쪽 PC 모두 현재 유효한 `file-transfer` 권한이 있어야 합니다.
- 서비스 시작, 파일 제안과 수락, 들어오는 데이터, 나가는 각 청크에서 권한을 다시 확인합니다.
- 실행 중 키가 제거되거나 만료되면 해당 세션은 실패하고 임시 상태를 정리합니다. 키를 다시 넣어도 실패한
  세션이 자동으로 재개되지는 않습니다.
- 보낼 때 파일 ID·크기·수정 시각을 다시 확인합니다. 받을 때는 소유한 숨김 임시 폴더에 기록한 뒤 크기와
  SHA-256을 검증하고, 같은 이름이 있으면 덮어쓰지 않는 이름으로 게시합니다.
- 파일 바이트는 기존 PC 간 TLS 연결을 사용하며 Ieum 운영 서버를 통과하지 않습니다.

## 오프라인 라이선스의 의미

현재 키는 Ed25519로 서명된 오프라인 권한증입니다. 앱에는 공개 검증키만 들어 있고 발급 개인키는 공개되지
않습니다. 인터넷 연결, 계정이나 활성화 서버가 없어도 검증할 수 있습니다.

이 단계에서는 장치 수를 세지 않고 장치에 키를 묶지 않으며 원격 회수도 하지 않습니다. 같은 후원자의 PC에는
같은 라이선스 파일을 사용할 수 있습니다. 결제, 계정, 좌석 관리, 환불 후 회수와 온라인 활성화는 향후 Pro
계정 서비스 단계입니다.

Ieum 데스크톱 소스는 계속 `GPL-2.0-only WITH LicenseRef-OpenSSL-Exception`으로 공개됩니다. 따라서 사용자가
소스를 수정해 라이선스 검사를 제거한 자체 빌드를 만드는 것까지 막는 DRM은 아닙니다. Pro Local 키는 공식
배포 바이너리에서 후원 기능을 여는 장치이며, GPL 소스 비공개화를 뜻하지 않습니다.

## 문제 해결

| 표시 | 확인할 내용 |
| --- | --- |
| Pro Local is locked | 키 파일을 가져온 뒤 **Activate**를 눌렀는지 확인합니다. |
| invalid format/signature | 파일을 편집하거나 여러 줄로 합치지 말고 전달받은 원본을 다시 가져옵니다. |
| not active yet | PC의 날짜·시간·시간대가 맞는지 확인합니다. |
| expired | 새 라이선스가 필요한지 발급자에게 확인합니다. |
| 전송 옵션이 비활성 | 양쪽 PC의 라이선스, Windows 플랫폼, 설정 쓰기 권한과 TLS를 모두 확인합니다. |

`alpha.21`은 프리릴리스입니다. 자동 테스트는 권한 철회, 프로토콜 한계, 소스 재검증과 임시 파일 정리를
검증하지만, 두 대의 실제 Windows PC에서 장시간·대용량 수용 검증을 완료했다고 주장하지 않습니다.
