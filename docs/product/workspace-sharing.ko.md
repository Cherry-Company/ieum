# 작업 공간 공유 미리보기

현재 개발본의 기능 안내입니다. 공개 배포본은 alpha.31이며, 구독 판매는
아직 시작하지 않았습니다. Windows↔macOS 실기기 검증이 남아 있습니다.

## 시작하기

1. 연결할 컴퓨터와 중앙 컴퓨터 모두 같은 최신 개발본으로 실행합니다.
   기존 이음 연결과 TLS 인증을 먼저 완료합니다.
2. 참여 컴퓨터에 필요한 플랜을 활성화합니다. 기존 Local 키는 파일 전송
   권한을 그대로 유지하며, 새 기능은 해당 등급의 구독 또는 이벤트 키가 필요합니다.
3. 상단 **작업 공간 공유**에서 컴퓨터와 기능을 선택합니다.
4. 상대 컴퓨터에서 공유를 허용합니다. 상대의 연결이 유지되는 동안 기능별 허용을 저장할 수도 있습니다.
   상대가 다시 연결하면 같은 이름이어도 새로 허용해야 합니다.

| 기능 | 플랜 | 동작 |
| --- | --- | --- |
| 오디오 듣기 | Professional 이상 | 상대의 시스템 출력 소리를 재생합니다. 마이크는 수집하지 않습니다. |
| 화면 보기 | Professional Max | 상대의 주 모니터를 최대 1280×720, 초당 5장으로 봅니다. |
| 선택한 컴퓨터 제어 | Professional Max | 주·보조 역할과 관계없이 이 컴퓨터의 물리 키보드·마우스로 상대를 제어합니다. |
| 동시 입력에 추가 | Professional Max | 허용한 여러 컴퓨터에 키, 포인터 이동, 버튼, 휠을 함께 보냅니다. 이 컴퓨터에도 입력됩니다. |
| 잠금·깨우기 연동 | Professional Max | 연결된 컴퓨터를 함께 잠그거나 화면을 깨웁니다. 로그인 잠금은 해제하지 않습니다. |
| 이미지 클립보드 | Professional Max | 기존 클립보드 공유 경로를 사용합니다. 이 패널에서 별도 세션을 시작하지 않습니다. |

화면 보기는 영상 감상용 스트리밍이 아닌 작업 확인용입니다. 다중 모니터
전체 전송이나 원격 화면 창 안에서 클릭하는 방식은 지원하지 않습니다.
입력 제어를 함께 켜면 물리 마우스와 키보드가 상대 데스크톱에 적용됩니다.
오디오는 한 컴퓨터에서만 받을 수 있고, 오디오를 받는 동안 다른 컴퓨터에
다시 보내지 않습니다. 소리의 순환을 막기 위한 제한입니다.

## 종료와 권한 취소

- **선택한 공유 중지** 또는 **모든 공유 중지**로 종료합니다.
- 패널을 닫아도 공유는 계속됩니다. 메인 화면과 트레이에서 진행 상태를
  확인할 수 있고, 트레이의 **작업 공간 공유 중지**로도 종료할 수 있습니다.
- 제어받는 컴퓨터에서 직접 입력하거나, 제어 중 **Ctrl+Alt+Esc**를 누르면
  원격 입력이 중지됩니다. 눌린 키와 버튼도 해제합니다.
- **저장된 허용 취소**는 진행 중인 공유를 모두 끝내고, 이후 요청마다 다시
  허용 여부를 확인하게 합니다.
- 연결 종료, 권한 만료, 응답 시간 초과 시 캡처·입력을 정리합니다.
  데스크톱이 잠기면 오디오·화면·입력 공유를 끝냅니다. 잠금·깨우기 연동은 유지합니다.

## 운영체제와 깨우기 조건

Windows 오디오는 기본 출력 장치의 WASAPI 루프백을 사용합니다. 출력 장치를
바꿨다면 공유를 다시 시작하세요. 관리자 앱에 입력하려면 이음도 같은 권한으로
실행해야 합니다. Windows 보안 데스크톱과 로그인 잠금을 우회하지 않습니다.

macOS 시스템 오디오 공유는 **macOS 13 이상**과 화면 기록 권한이 필요합니다.
입력 제어에는 손쉬운 사용과 입력 모니터링 권한이 필요할 수 있습니다.
권한을 바꾼 뒤에는 이음을 다시 실행하세요. 권한 요청과 실제 오디오 장치는
실기기 검증 대상으로 남아 있습니다.

Linux의 새 화면·물리 입력 기능은 X11에서 제공하며, 오디오는
PulseAudio 또는 PipeWire의 PulseAudio 호환 서비스와 `parec`, `pactl`, `paplay`가
필요합니다. Debian/Ubuntu에서는 `pulseaudio-utils` 패키지를 사용합니다.
잠금 확인에는 logind 세션이 필요합니다. 잠금 상태를 확인할 수 없으면 공유를
허용하지 않습니다. 새 기능의 Wayland·Flatpak 지원은 포함하지 않습니다.

**컴퓨터 깨우기**는 이미 연결해 주소를 저장한 컴퓨터에 LAN 브로드캐스트로
Wake-on-LAN 패킷을 보냅니다. BIOS/UEFI, 네트워크 어댑터, 전원 설정과 네트워크가
이를 지원해야 합니다. Wi-Fi, 인터넷, Tailscale을 통한 절전 해제는 보장하지
않습니다. 화면 깨우기와 절전 해제 모두 로그인 암호를 대신 입력하지 않습니다.

## 현재 검증 범위

Linux 빌드, 자동화된 세션·프로토콜·IPC 검증, 가상 X11 데스크톱과 가상 오디오
장치를 사용한 네이티브 경로 검증을 통과했습니다. Windows 백엔드는 Windows
헤더를 사용한 교차 문법 검사를 통과했습니다. Windows/macOS 완성 패키지 빌드와
실제 두 컴퓨터 사이의 오디오·한글 입력·권한·잠금·재부팅 검증은 별도입니다.

무료 호스팅 한도는 무중단 구독 서비스를 보장하지 않습니다. 판매 계정과 운영
인증, 장애 시 갱신 정책 및 실제 결제·갱신·환불 검증을 마치기 전에는 판매를
활성화하지 않습니다. [플랜과 가격 근거](professional-plans.md)를 참고하세요.
