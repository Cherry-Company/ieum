# Professional plans

Status: implementation in progress. This document describes the requested
product packaging, not a claim that the new features or checkout are live.
The published release remains alpha.31 until the release checks below pass.

## Product rules

| Plan | Includes |
| --- | --- |
| Free | Keyboard and mouse sharing, Korean/English input synchronization, text clipboard, encrypted local connections |
| Professional Local | Free plus direct file transfer |
| Professional | Local plus computer audio sharing |
| Professional Max | Professional plus control from either computer's keyboard/mouse, remote screen viewing, image clipboard, coordinated lock/wake, and simultaneous input |

Paid plans are cumulative. The ordinary purchase path is a subscription.
The separate event-license field accepts signed promotional and owner licenses.
Existing signed Pro Local licenses retain their original expiration, including
perpetual file-transfer access. A subscription ending must not erase a valid
legacy or event license or stop free input sharing.

Image clipboard and keyboard broadcast already exist in the inherited core.
Moving them into Max changes the entitlement policy; it is not new feature
development. That change must be disclosed in the release notes. Audio,
bidirectional control and remote viewing require native implementation and
cross-computer acceptance before they can be sold as available.

## Implementation status

The current branch contains the four-tier catalog, v2 signed entitlements,
separate event/subscription authorities, legacy-license fallback, periodic
subscription refresh, a translated plans dialog, and activation-link handling.
The owner-only issuer and subscription API are separate private workspaces.
Native Linux builds, license boundaries and local API fixtures have been tested.

Audio capture/playback, remote screen transport and bidirectional input
ownership are not implemented in this branch. Coordinated lock/wake remains
incomplete. Image clipboard and keyboard broadcast now check the Max entitlement
in the core. Free clipboard sharing retains plain text, including text copied
alongside an image; HTML is excluded because it can embed images. Broadcast
repeats and key releases follow the original recipient set through a mode change,
license expiry or peer disconnect. This is keyboard broadcast, not completed
mouse broadcast or control from a secondary computer's physical keyboard.
The six-feature bundle is not ready for public sale.

Checkout is unavailable in the desktop until a verified HTTPS service address
is set through the release-time CMake option `IEUM_SUBSCRIPTION_SERVICE_URL`.
It accepts an HTTPS origin; neither a receipt nor user settings can override the
server receiving recovery codes. The Paddle checkout page runs on this same
origin, with a durable private purchase database. Hosting is independent of Vercel.
After server-verified payment, activation links prefill the selected plan and a
masked recovery code; the user selects Restore. The code is saved from the Ieum
checkout page, not generated by Paddle or included in its receipt. Installer
registration and actual checkout still require Windows/macOS acceptance.

## Initial price hypothesis

All amounts are USD before any applicable checkout tax. Annual billing is shown
first, with the full annual charge visible; monthly billing is an alternative.

| Plan | Monthly | Annual | Annual saving against 12 monthly payments |
| --- | ---: | ---: | ---: |
| Free | $0 | $0 | — |
| Professional Local | $1.99 | $14.99 | 37.2% |
| Professional | $2.99 | $24.99 | 30.4% |
| Professional Max | $4.99 | $39.99 | 33.2% |

This is a launch hypothesis based on the public offers below, not measured
willingness to pay or a guaranteed conversion forecast. The distinguishing
value is a Windows/Mac workflow with Korean input support. Neither encryption
nor recovery from a failed payment is sold as a premium feature. Cancellation
must be accessible, with access continuing through the paid period.

## Payment provider decision, checked 2026-11-06

The user selected **Paddle**. The planning assumption is a Korean sole proprietor
selling globally, possibly incorporating later. Neither approval nor a legal-entity
migration has been verified for this seller. There is no merchant account or live
checkout yet. The following comparison records the decision's cost context.

| Provider | Published cost for a new seller | Assessment for Ieum |
| --- | --- | --- |
| [Polar](https://polar.sh/resources/pricing) | Starter: 5% + $0.50; +1.5% for non-US cards. No monthly fee. Payout and conversion costs are additional. | Alternative with hosted subscriptions and built-in license benefits; [South Korea is on the payout list](https://polar.sh/docs/merchant-of-record/supported-countries). |
| [Paddle](https://www.paddle.com/pricing) | Published all-inclusive 5% + $0.50; contact sales for products under $10. | Selected software subscription/MoR provider. [Sellers worldwide except listed exclusions](https://www.paddle.com/help/start/account-verification/which-countries-are-supported-by-paddle); South Korea is not excluded. [Sole traders skip the separate business-identification step](https://www.paddle.com/help/start/account-verification/what-is-business-verification); domain/identity checks still apply. |
| [Lemon Squeezy](https://docs.lemonsqueezy.com/help/getting-started/fees) | 5% + $0.50; +0.5% subscriptions; +1.5% international; additional PayPal/payout charges can apply. | Korean payout eligibility needs confirmation for the actual seller and payout route. Base fee alone does not establish the easiest onboarding. |
| [Gumroad](https://gumroad.com/help/article/66-gumroads-fees) | Direct: 10% + $0.50, **plus card processing 2.9% + $0.30**. Discover: 30% including processing. | Simple storefront, but too expensive for Ieum's low monthly prices. No longer the recommended default. |

The earlier Gumroad comparison omitted the separately charged card-processing
fee. At $1.99, the combined direct card fee is approximately $1.06 (53.1%). At
$14.99 it is $2.73 (18.2%). This correction materially changes the recommendation.
Polar's 4% + $0.40 Early Member price does not apply to a new account: it is for
organizations created before May 27, 2026. The table uses new-seller pricing.

At Paddle's published standard rate, a $14.99 annual sale leaves approximately
$13.74 before tax effects, refunds, disputes or any seller-specific terms. At
$1.99 monthly, the standard fee consumes about 30.1%; ask Paddle about sub-$10
pricing and retain annual billing as the default, with the full charge shown.
These arithmetic examples are not a net-profit forecast or a negotiated quote.

The separate service defaults to Paddle, retaining Polar/Gumroad reference
adapters, a stable plan catalog and its own subscription signing authority.
Paddle supports PayPal and [recurring KakaoPay/NaverPay payments](https://developer.paddle.com/changelog/2025/recurring-kakaopay-naverpay-subscriptions)
for Korean buyers in KRW, subject to actual merchant/currency configuration.
Local prices and wallet availability must be checked with the approved account.
The app accepts only the compiled service origin's known checkout paths or
allowlisted legacy provider paths. Recovery credentials cannot change that origin.
The private owner/event authority remains separate. A future legal-entity change
requires the provider's approval and payout-account review; changing business
registration alone does not migrate live subscriptions. Preserve the old payment
account and refresh path until a verified migration is complete. Do not rotate
Ieum license authorities merely because the business entity changes.

Paddle Billing [does not generate license keys](https://developer.paddle.com/migrate/plan).
The service therefore issues its own random recovery credential, stores only
its hash and purchase mapping in D1 (or SQLite in the optional Node adapter), and binds it to a server-created Paddle
transaction. Browser completion alone never activates a tier. API version 1
verification checks the original transaction/nonce, customer, active subscription,
exact product/price, current paid period and transaction adjustments. Trials,
unpaid periods, full refunds and active chargebacks cannot mint paid access.
Partial refunds retain access; period-end cancellation retains the paid period.

The desktop refreshes hourly. Leases last at most seven days, capped by paid and
scheduled ends; outages preserve existing signed access. No webhook endpoint or
instant offline revocation is implemented. Fully paid tier changes at billing
boundaries are supported; mid-period proration, mixed/add-on items and automatic
plan-change UI are not. Use separate event licenses for free promotions. The
receipt's customer portal manages billing, while the Ieum page provides recovery
code download and an activation link. Operator recovery verifies the original
transaction before rotating a lost code; automatic email recovery is not present.

The owner requires zero hosting cost. The selected service uses Cloudflare
Workers + D1 **Free**, initially on workers.dev with an owned subdomain connected
later. No blockchain is needed. The private service includes a Worker entrypoint,
D1 migration, primary-session purchase checks, conditional credential rotation
and a private operator recovery tool. Local runtime tests cover persistence and
payment verification; no Cloudflare account or remote deployment is connected yet.

As checked on 2026-11-06, [Workers Free](https://developers.cloudflare.com/workers/platform/pricing/)
allows 100,000 requests/day and 10ms CPU per invocation;
[D1 Free](https://developers.cloudflare.com/d1/platform/pricing/) allows 5 million
rows read/day, 100,000 rows written/day and 5GB total storage, with a
[500MB per-database limit](https://developers.cloudflare.com/d1/platform/limits/).
Free-plan excesses fail requests; do not upgrade to Paid. Limits are shared with
other account workloads. Production CPU usage still needs measurement. Per-IP
and per-location request controls reduce abuse but are not a global quota.
Quota/DB failures preserve an existing signed lease until expiry, at most seven
days. Paddle fees and domain renewal are separate from hosting costs.

Database and signing-authority backups remain required. A single-instance Node 24
SQLite/Caddy adapter is retained for an existing server; its filesystem must be
persistent. Public checkout stays disabled until native features,
merchant onboarding and live purchase/renewal/cancel/refund checks pass. The
fixture tests do not establish a successful real-world payment.

## Before public sale

- Real approved seller account, product IDs, monthly/annual prices and checkout URLs.
- Private signing authority backed up outside Git and release artifacts.
- Correct permissions in GUI and core, on both peers where applicable.
- Renewal, scheduled cancellation, expiry, refund, wrong-product and offline tests.
- Windows/Mac physical acceptance of audio, capture permission, input ownership,
  key release, clipboard, lock/wake and simultaneous input.
- Translated in-app plans and README agree with actual released capabilities.
- Production checkout and activation tested with the configured provider.
- Native build/package checks and published installer checksum verification.
