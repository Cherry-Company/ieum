# 이음 유료 기능 후보 (제안)

작성일: 2026-07-28 · 상태: **제안이며 확정된 상품 계획이 아님**

이 문서는 "사람들이 돈을 낼 수밖에 없는" 이음 유료 기능 후보를 정리합니다. 판단 기준은 세 가지입니다.

1. **매일 여러 번 겪는 짜증**을 없애는가 (연 1회 쓰는 기능은 결제 이유가 되지 않음)
2. **이음만 구조적으로 할 수 있는가** — 입력 소스 상태 채널(`DILC`/`CILS`)과 원시 스캔코드 경로를
   이미 가진 제품만 가능한 기능인가
3. **GPL 경계 안에서 지속 가능한가** — 코어를 잠그지 않고도 과금 근거가 서는가

## 0. 과금 경계 원칙

코어는 `GPL-2.0-only`입니다. 실행 파일 안에 기능을 넣고 잠그는 모델은 README의 공개 방침과도
충돌하고, 어차피 누구나 재빌드할 수 있어 방어되지 않습니다. 따라서 다음 원칙을 씁니다.

> **기능 자체는 무료로 풀고, 그 기능의 "상태가 내 모든 기기를 따라다니는 것"을 판다.**

| 과금 가능 | 이유 |
| --- | --- |
| 계정·기기 발견·릴레이·프로필/히스토리 동기화 | 호스팅 서비스이므로 GPL 배포 의무와 무관 |
| 서명·공증된 공식 빌드와 안정 업데이트 채널 | 바이너리 신뢰와 운영 편의에 대한 비용 |
| 큐레이션 데이터(앱별 IME 프리셋, 오타 복구 사전) | 지속 갱신되는 데이터·서비스 |
| 팀 정책, SSO, 감사 로그, 배포 지원 | 조직 운영 가치 |

로컬 단일 사용은 계속 무료 — 이게 유입 경로이자 홍보 수단입니다.

## 1. S급 — 이음만 할 수 있고, 하루에 열 번 겪는 문제

### 1-1. 한/영 오타 타임머신

`dkssudgktpdy` → `안녕하세요`, `ㅗ디ㅣㅐ` → `hello`. 핫키 한 번으로 마지막 입력 구간을 반대 언어로
다시 칩니다.

**이음만 가능한 이유**: 기존 유틸은 화면의 텍스트를 읽어 "무엇을 치려 했는지" 추측합니다. 이음은
서버가 **실제로 눌린 물리 키 시퀀스와 그때의 IME 상태**를 이미 알고 있으므로, 추측 없이 원래 키를
반대 상태로 재생하면 끝입니다. 정확도의 차원이 다르고, 맥에서 치다가 윈도우로 넘어간 구간에도
그대로 적용됩니다.

**구현 위치**: 서버 키 경로에 최근 N개(스캔코드 · IME 상태 · 타임스탬프) 링 버퍼를 두고,
`src/lib/server/InputFilter.h:256`의 `KeystrokeAction` 옆에 복구 액션을 추가합니다. 복구 동작은
`BackSpace × N` → `DILC`로 입력 소스 전환 → 원시 스캔코드 재전송입니다. 되돌릴 구간은 마지막 IME
세션 경계(`CILS`의 composing 플래그 전이)로 한정해 과다 삭제를 막습니다.

**경계**: 로컬 동작 무료. 유료는 자동 감지 교정(사용자가 핫키를 누르지 않아도 오타를 판정),
앱별 예외 목록, 오타 판정 사전의 갱신 배포.

**난이도**: 중 · 실기 검증 필요(백스페이스 개수 오판이 가장 큰 리스크)

### 1-2. 앱별 한/영 기억 (Context IME)

터미널·IDE로 포커스가 가면 영문, 카톡·노션·한글로 가면 한글. 사용자가 고칠 때마다 학습하고,
**기기가 바뀌어도 그 앱의 상태가 따라옵니다**.

**현재 상태**: 화면 진입 시 언어 정책(`keep` / `force-en` / `follow-server`)이 이미
`src/lib/server/Server.cpp:1677`과 설정 UI에 있습니다. 이 정책의 단위를 "화면"에서 "앱"으로
내리는 확장입니다.

**구현 위치**: 클라이언트가 포그라운드 앱을 감지해(Windows `GetForegroundWindow` + 프로세스명,
macOS `NSWorkspace.frontmostApplication`) 서버에 보고하고, 서버 규칙 엔진이 `DILC`로 상태를
지정합니다. 보고 채널은 `CILS`와 같은 계층에 메시지 하나를 추가하면 됩니다.

**경계**: 로컬 수동 규칙 무료. **규칙 프로필의 기기 간 동기화와 수백 개 앱 기본 프리셋이 유료.**
"새 노트북 사서 로그인만 하면 내 한/영 습관이 그대로" — 이게 결제 문장입니다.

**난이도**: 중 · 플랫폼별 포그라운드 감지 권한 확인 필요

### 1-3. 화면 경계 조합 이월 (Preedit carry-over)

`한`을 조합하는 중에 마우스가 옆 컴퓨터로 넘어가면 글자가 깨지거나 사라집니다. 이음은 `CILS`로
조합 여부를 이미 받고 있으므로(`ProtocolTypes.cpp:46`, 세 번째 필드가 composing), 경계를 넘기
직전에 **안전 커밋**하거나 미완성 조합을 반대편에서 **이어서 조합**할 수 있습니다.

**경계**: 무료. 다른 KVM은 원리상 못 하는 시그니처 기능이라 유입용으로 쓰는 편이 낫습니다.

**난이도**: 중상 · 조합 상태 왕복 지연이 관건

## 2. A급 — 결제 버튼을 누르게 만드는 생활 편의

### 2-1. 유니버설 클립보드 프로 (한글 기준)

히스토리 · 초성 검색(`ㅇㄴㅎㅅㅇ` → `안녕하세요`) · 고정 · 이미지/파일 · **macOS NFD ↔ Windows NFC
양방향 자동 정규화**(본문과 파일명 모두).

**현재 상태**: 단방향 NFC 정규화가 `src/lib/platform/OSXClipboardAnyTextConverter.cpp:16`에 있고
설정 키는 `client/clipboardNormalizeNFC`입니다. 여기에 히스토리와 검색을 얹는 확장입니다.

**차별점**: 애플 유니버설 클립보드는 맥↔아이폰 전용입니다. 윈도우↔맥에서 한글 자소 분리 없이
되는 제품은 사실상 없습니다.

**경계**: 최근 N개 로컬 히스토리 무료. **기기 간 동기화, 무제한 보관, 팀 공유가 유료** —
호스팅이라 GPL 경계가 가장 깨끗합니다.

**난이도**: 중

### 2-2. 붙여넣기 안 되는 곳에 한글 타이핑 (Type-as-keystrokes)

회사 VDI, RDP, VMware/Proxmox 콘솔, 스위치 시리얼 콘솔, IPMI/iDRAC, 화면 공유 창 — 클립보드
공유가 막힌 환경에 한글을 **키 입력으로 정확히 타이핑**합니다. 이음은 IME 상태를 알기 때문에
조합이 깨지지 않고, 보안팀의 클립보드 정책도 건드리지 않습니다.

**대상**: 금융·공공·대기업 VDI 사용자와 인프라 엔지니어. 지갑이 가장 빨리 열리는 집단입니다.

**난이도**: 중 · 원시 스캔코드 경로(`client/cjkRawScancode`)를 재사용

### 2-3. 크로스 머신 텍스트 확장

`;주소` → 회사 주소, `;계좌` → 계좌번호, `;서명` → 메일 서명. 국산 스니펫 도구의 고질적인 한글
조합 깨짐이 없습니다(IME 상태 인지형이므로).

**경계**: 로컬 스니펫 무료, **동기화와 팀 공유 스니펫이 유료**.

**난이도**: 하 — 1-1의 링 버퍼·재생 인프라를 그대로 재사용

### 2-4. 파일 드래그 앤 드롭 신뢰성

드래그 전송 배관은 이미 있습니다(`src/lib/server/ClientProxy1_5.h:26`의 `sendDragInfo`,
`fileChunkSending`). 여기에 **한글 파일명 정규화**, 폴더 전송, 이어받기, 진행률을 더합니다.
한글 파일명이 `ㅍㅏㅇㅣㄹ.txt`로 깨지는 문제는 정규화 코드를 파일명 경로에도 태우면 해결됩니다.

**난이도**: 중

## 3. 팀/클라우드 — 실제 매출이 나오는 층

### 3-1. 이음 클라우드 (계정 · 기기 발견 · 릴레이)

지금은 Tailscale 수동 설정이 진입장벽입니다(`src/lib/common/TailscaleIntegration.cpp`).
**설치하고 로그인만 하면 내 기기가 목록에 뜨고 바로 연결**되는 경험은 그 자체로 정당한 과금
근거이며, 서버 서비스라 GPL과 무관합니다. 집↔사무실처럼 NAT을 넘는 연결도 여기서 풀립니다.

### 3-2. 조직 기능

팀 정책 배포, SSO, 감사 로그, MDM 대량 배포, 우선 지원. README의 Teams/Cloud 방향 그대로입니다.

### 3-3. 서명된 공식 빌드와 안정 업데이트 채널

설치할 때 경고창이 뜨지 않는 것 — 기업 구매에서는 이것만으로도 결제 사유가 됩니다. 로드맵에
이미 있고, `docs/dev/update-delivery.md`의 기준을 충족한 뒤 켜야 합니다.

## 4. 티어 제안

| 티어 | 내용 |
| --- | --- |
| **Community** (무료) | 로컬 KVM, IME 동기화, 오타 타임머신(핫키), 조합 이월, 로컬 클립보드 히스토리·스니펫 |
| **Ieum Plus** (개인 구독) | 기기 간 프로필·클립보드·스니펫 동기화, 앱별 IME 프리셋, 자동 오타 교정, 클라우드 기기 발견·릴레이, 서명 빌드와 안정 업데이트 |
| **Ieum Teams** (사용자당) | 팀 정책, 공유 스니펫, SSO, 감사 로그, 배포 지원 |
| **Enterprise** | 계약 지원, 온프레미스 릴레이, 유지보수 |

가격은 별도 검토 대상입니다. 다만 개인 티어는 "커피 한 잔" 심리선(월 4~6천 원대) 안에 두고,
결제 이유를 **기능 잠금이 아니라 기기 간 연속성**으로 설명하는 편이 이 프로젝트의 공개 방침과
일관됩니다.

## 5. 구현 순서 제안

1. **오타 타임머신** — 무료로 풀어 유입을 만든다. 링 버퍼·재생 인프라가 이후 기능의 토대가 된다.
2. **앱별 한/영 기억(로컬)** — 무료. 동기화 훅을 붙일 자리를 만든다.
3. **클립보드 히스토리·초성 검색(로컬)** — 무료.
4. **계정과 동기화 서비스** — 1~3의 상태를 기기 간에 이어주는 첫 유료 상품.
5. **VDI 한글 타이핑, 파일 전송 신뢰성** — 기업 영업 대화의 진입 문.
6. **팀 기능과 서명 빌드** — 조직 결제.

## 6. 수용 기준(제안)

기능마다 다음을 만족하기 전에는 유료 상품으로 광고하지 않습니다.

- 오타 복구: 20회 연속 복구에서 과다 삭제 0건, 복구 후 IME 상태 불일치 0건
- 앱별 IME: 앱 전환 20회에서 상태 오적용 0건, 전환 수렴 500ms 이내
- 클립보드: 맥↔윈도우 왕복에서 자소 분리 0건(본문·파일명 모두)
- 공통: 입력 지연 p95 증가 2ms 미만 — 기존 `phase0_report.md` 기준과 동일
