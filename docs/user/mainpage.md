# Ieum User Guide

Ieum shares one keyboard and mouse across nearby computers and synchronizes IME state between Windows and macOS.

- [Korean installation and first connection guide](../../README.md#설치와-첫-연결)
- [IME synchronization](ime.md)
- [Configuration reference](configuration.md)
- [Project releases](https://github.com/YijiOS/ieum/releases)

The desktop application is named `Ieum`. Current packages use the Ieum-owned `ieum-core` and `ieum-daemon`
helpers. Linux retains the upstream `org.deskflow.deskflow` application ID for Flatpak compatibility.
