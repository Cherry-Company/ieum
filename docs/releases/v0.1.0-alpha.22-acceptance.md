# Ieum v0.1.0-alpha.22 acceptance

## Release scope

- Bidirectional Pro Local file copy between Windows and macOS.
- Either application role may originate a configured screen-edge drop.
- Offline perpetual `file-transfer` entitlement on both computers.
- USD 30 one-time, limited-window GitHub Sponsors Early Access with manual payment verification and email delivery.
- No Ieum account, activation server, hosted storage, or relay is involved in Pro Local transfer.

The public desktop remains `GPL-2.0-only WITH LicenseRef-OpenSSL-Exception`. The private issuer, signing key,
ledger, receipts, and generated licenses are not part of this repository or any release artifact.
